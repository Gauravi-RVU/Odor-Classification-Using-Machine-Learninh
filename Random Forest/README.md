# Team_7_IML_Project


Scent Classification Using Random Forest
This project uses a Random Forest classifier to predict the scent family of chemical compounds based on concentrations of various chemicals recorded by sensors. It achieves an accuracy of 95% on the test set.

Model Info
Model Type: Random Forest Classifier
Features Used: 16 chemical compound concentration values
Target: Scent family (multi-class classification)
Dataset Size: 5000 samples
Train/Test Split: 80% / 20%

Files Description


random_forest.ipynb : 	ipynb notebook to train a Random Forest model on the odor dataset


label_encoder.pkl : 	Stores the label encoder used to transform string class labels to integers.


decision_tree_perfume_sir.pkl : Saved Random Forest model.


odor_dataset_final.csv : The dataset used for training and testing the model.
